# ubsHero Component

This component displays a full-width responsive hero banner with a background image and an overlay content panel, designed in a clean, minimal style similar to UBS.

## Features

- Full-width hero image.
- Overlay panel for text content and a call-to-action.
- Responsive design that stacks content on mobile devices.
- Clean, UBS-inspired styling with a red accent line.

## Authorable Properties

The following properties can be configured in the component's dialog:

- **Background Image**: The main image for the hero banner. (Required)
- **Headline**: The main title text in the overlay.
- **Eyebrow Text**: A smaller line of text appearing above the headline.
- **Description**: A paragraph of text below the headline.
- **CTA Button Text**: The text for the call-to-action button.
- **CTA Button Link**: The destination link for the CTA button.
- **Overlay Position**: Controls the alignment of the content overlay. Options are: Bottom Left (default), Bottom Right, Top Left, Top Right.
